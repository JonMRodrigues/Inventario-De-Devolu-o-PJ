# Inventario-De-Devolu-o-PJ
Sistema web de auditoria de devoluções. O auditor escolhe o PJ e bipa os códigos, que são validados (só letras e números) e checados contra duplicidade, com limite de 2.500 peças. Permite consultar a lista e, ao exportar, baixa Excel e PDF juntos e reinicia a auditoria. Dados salvos no navegador, visual Windows XP.
